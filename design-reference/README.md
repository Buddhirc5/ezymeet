## Visual language
- Primary: deep navy / indigo (`~#14125E`); accent: red (`~#C8102E`) for marketing backgrounds and badges.
- White cards with soft shadows and rounded corners (~12–16px); light grey dividers.
- Outlined line icons in navy, centered in square tiles.
- Full dark theme supported; dashboard sections are user-configurable widgets.
- Clean sans-serif typography, bold headings, generous spacing.
